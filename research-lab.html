NEIL / FIVE RESEARCH ENGINES

研究工具中心.

從互動圖表、個人 ETF 行情研究，到投資儀表板、研究報告輸出與回測專案。這五個工具已納入 GitHub 專案，但各自需要的執行環境並不相同。

01 / VISUAL ANALYTICS

Plotly

用官方美債歷史資料產生 1M–30Y 互動殖利率曲線；Python 產生器已加入研究工具，網站亦設有可直接操作的互動圖表。

網站互動圖表可閱讀 · Plotly.py 由 GitHub Actions 安裝測試
開啟互動殖利率圖表 ↗ 檢視 Plotly Python 程式
02 / PERSONAL MARKET RESEARCH

yfinance

私人研究 VT、VOO、GLD、XLV 等 ETF 歷史行情。程式僅在有 Python 的工作環境執行，預設不把 Yahoo 資料自動發布到公開網站。

私人研究腳本已建立 · 不公開 Yahoo 歷史資料
查看私人 ETF 行情工具 ↗ yfinance 官方專案
03 / INTERACTIVE INVESTING

Streamlit

已準備可部署的投資研究儀表板：選擇官方觀測指標、篩選歷史區間、查看互動圖表並下載 CSV。需要在 Streamlit Community Cloud 額外完成登入部署。

應用程式碼與 requirements 已建立 · 尚待外部託管
前往 Streamlit 部署 ↗ 設定檔：research/streamlit_app.py
04 / FINANCIAL EDITORIAL

Quarto

根據已保存的 Treasury／ECB 資料，自動產生 Quarto 市場簡報 HTML。可從 GitHub Actions 取得報告附件，與主站發布互不干擾。

報告產生器與 CI 已設定 · 測試報告作為 Artifact
Quarto 產出與下載 ↗ 查看 Quarto 報告產生器
05 / PORTFOLIO STRATEGIES

QuantConnect LEAN

建立季度調整的 VT／AGG／GLD 策略範例，可作為學習配置與回測的起點。真正執行需要 Docker、資料來源及 QuantConnect 帳號／訂閱權限。

策略程式碼已建立 · 未執行雲端或本機回測
查看 LEAN 策略程式 ↗ LEAN CLI 官方要求
GITHUB / OPERATIONS

安裝及驗證紀錄

GitHub Actions 驗證 Plotly、yfinance、Streamlit 的 Python 環境，Quarto 產製報告；LEAN CLI 可在手動執行選項中測試，回測則需另行設定。

開源工具原始碼集中管理 · 不會更改每日官方行情更新排程
