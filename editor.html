無須寫程式：輸入文章、下載更新檔，再上傳至 GitHub 即可發布。

重要：這是完全在瀏覽器內運作的前端編輯工具，按「產生檔案」不會自動發布，也不會把內容傳到伺服器。產生的 reports.js 需由你登入 GitHub 後上傳並取代同名檔案；請不要輸入任何私密客戶資料。

iPad 發布步驟

  1. 填好文章，點「下載更新後的 reports.js」。
  2. 打開自己的 GitHub 網站專案。
  3. 找到 reports.js，上傳並取代同名檔案，或貼上複製的內容後 Commit。
  4. 回到公開網址重新整理，就能看到新報告。
